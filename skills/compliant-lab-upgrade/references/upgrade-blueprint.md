# 高深度升级的分层蓝图

## 设计目标

「复杂度和深度」不是多加几个页面，而是让项目具备**可计算、可验证、可复现、可迁移**的能力。每一层都必须是平台无关的纯逻辑，能独立写单测，不依赖 UI 与浏览器 API。

## 六层结构

```
src/
├── kernel/        第 1 层：科学计算内核（纯函数，零依赖，零 DOM）
├── experiments/   第 2 层：包 DSL v2 + 校验器 + 注册中心
├── learning/      第 3 层：学习科学与持久化
├── report/        第 4 层：可复现性与结构化报告
├── assistant/     第 5 层：离线检索增强助教
└── components/    第 6 层：界面接线（薄，不含业务逻辑）
```

### 第 1 层 · 数值内核

| 模块 | 建议能力 | 验收点 |
|---|---|---|
| `linalg` | 部分主元 LU、Cholesky、逆矩阵、行列式、条件数、加权正规方程 | 跨 1e8 量级矩阵不丢精度；奇异矩阵可检测 |
| `ode` | Euler / 辛 Euler / Velocity Verlet / RK4 / Dormand-Prince RK45 自适应步长、事件零交叉、能量漂移诊断、求解器对比 | 谐振子能量守恒辛格式显著优于显式 Euler；事件定位精度 |
| `expr` | Tokenizer + Pratt 解析器 + 闭包编译，支持 `^` 右结合、一元负号、函数白名单 | **禁用 eval**；未知标识符返回 NaN 而非抛错；常量可被变量覆盖 |
| `units` | SI 7 维量纲向量、单位别名、复合单位、量纲一致性批量校验 | 能定位具体哪一对量纲不一致 |
| `fit` | WLS 线性、多项式、Levenberg–Marquardt 非线性；R²/调整 R²/RMSE/CI/AIC/BIC | 带噪声时置信区间覆盖真值 |
| `stats` | 描述统计、IQR/Grubbs 离群点、GUM 一阶传播、蒙特卡洛传播、FFT/PSD/主频、Welch t 检验 | 线性模型下 MC 与 GUM 结果一致 |
| `circuit` | MNA stamping、二极管 Newton-Raphson + gmin stepping、C/L 后向欧拉 companion、瞬态、AC 实嵌入扫频 | 分压电路、RC 充电曲线、截止频率增益 1/√2 |
| `rng` | 可复现种子、正态采样、按标签派生子流、稳定序列化 | 同种子逐位一致；键顺序无关 |

**设计要点**：所有模块导出纯函数或不可变数据结构；随机数通过显式 `seed` 传入，绝不用 `Math.random()`；这样快照复跑才成立。

### 第 2 层 · 包 DSL v2

- `meta`：DSL 版本、作者、许可证、思想来源、教学目标、标签。
- `solver`：声明式描述求解类型、方程、状态变量、参数、初值、能量表达式、事件。
- `analysis`：声明拟合、不确定度、频谱、离群点等分析意图。
- 自研 JSON-Schema 子集校验器：避免引入 ajv 等依赖，且能自定义语义校验（交叉引用、方程与状态变量数量一致、答案下标越界）。
- 运行时注册中心：内置包编译期注册、外部包从内存字符串注册（**不要 fetch**，WebView / 离线场景要能工作）。
- V1 → V2 迁移：**不臆造许可证**，迁移只补结构字段，来源不明保持待补状态。
- 无 TS 逻辑的外部包：由 `GenericNumericLogic` 读 `solver` 声明直接驱动内核运行。

### 第 3 层 · 学习闭环

- 持久层：IndexedDB 为主，内存 / localStorage 镜像降级；必须能迁移旧版 localStorage 数据。
- 多学习者档案与切换。
- BKT 贝叶斯知识追踪（先验、学习率、猜对率、失误率）。
- D/S/R 三变量记忆模型 + 幂律遗忘曲线 + SM-2 风格排程。
- 错题本：去重收集、复习、连续正确毕业阈值。
- 推荐器：掌握度 × 遗忘曲线 × 薄弱实验 × 错题密度 → 学习路径。
- **重点**：把旧版本里的 `overallProgress / weakExperiments` 之类死代码真正接通，而不是另起一套。

### 第 4 层 · 可复现性与报告

- 纯 TS SHA-256（不依赖 `crypto.subtle`，WebView 常不可用）。
- 快照格式带 schema 版本：参数、种子、求解器配置、原始数据、拟合结果、校验和。
- 校验和计算前先 `JSON.parse(JSON.stringify(x))` 归一化，否则内存对象与 JSON 往返字段集合不同。
- 报告结构化章节：信息 / 目的 / 方法 / 数据 / 拟合 / 频谱 / 不确定度 / 结论 / 可复现性 / 参考致谢。
- 导出：Markdown、自包含 HTML（内嵌 SVG 曲线，无外链）、CSV、快照 JSON。
- 大数据量曲线用 min/max per pixel column 抽稀，别把 10 万点直接塞进 SVG。

### 第 5 层 · 离线助教

- BM25 检索，中文二元字 gram + 英文 token 混合分词。
- LaTeX 子集渲染（分数、上下标、根号、希腊字母），避免引入 KaTeX/MathJax。
- 数据诊断规则：样本量、R²、离群点、量纲、能量漂移。
- 可插拔 `LLMAdapter` 接口：默认 `null`（全离线），外部适配器失败自动回退到检索结果。

### 第 6 层 · 界面接线

- 新增「数值研究台」：暴露求解器切换、求解器对比、拟合、频谱、不确定度、快照与报告导出。
- 新增「学习中心」：掌握度、错题复习、推荐路径、档案、快照、包管理、助教。
- 原实验台补：数据分析弹窗、保存快照、报告 3.0、题库逐题作答明细（用于喂 BKT 与错题本）。
- 界面层保持薄：只做参数收集与结果展示，计算全部调用下层。

## 主/副线协同

若项目有「PC 主线 + 移动端 WebView 副线」：

- 新功能**只在主线实现一次**，副线复用同一套 `src/`。
- 副线构建需 IIFE + 单文件全内联（WebView 常通过 `resource://` 加载，无法发网络请求）。
- 因此内核不得依赖动态 import、fetch、`crypto.subtle`、Web Worker。
- 副线构建完成后再跑内联脚本，删除 assets 目录，校验单文件体积。

## 版本迁移顺序

1. 先修存量契约不一致（类型定义与 JSON 实际字段对不上），否则升级会放大 bug。
2. 再加新内核与测试。
3. 再扩展 DSL 并批量迁移存量包。
4. 再接学习闭环与报告。
5. 最后接线 UI、补文档与 CI。

每步之后跑一次 `typecheck + test`，别攒到最后一起调。
