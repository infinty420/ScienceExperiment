## 0. 为什么要升级：V2 的四个结构性瓶颈

| 瓶颈 | 现状证据 | V3 对策 |
|---|---|---|
| 物理深度不足 | 27 个实验中仅 2 个真正用 `cannon-es`；其余是解析公式/脚本驱动，单摆为半隐式欧拉、简谐为 `x=A·cos(ωt)` 闭式解 | 引入统一 ODE 内核：多求解器 + 自适应步长 + 事件检测 + 能量守恒诊断，实验可声明动力学方程 |
| 数据分析停留在「画曲线」 | `DataPanel.vue` 自绘 canvas，仅线性拟合；蒙特卡洛误差散在逻辑里 | 引入拟合/统计/不确定度/频谱内核：WLS、Levenberg–Marquardt、R²、置信区间、GUM + MC、FFT/PSD、离群点 |
| 学习闭环断链 | `progress.ts` 的 `overallProgress/weakExperiments/entryScore` 定义但无人调用；持久化仅 localStorage（上限 100 条） | IndexedDB 持久层 + BKT 掌握度 + 错题本 + SM-2/遗忘曲线排程 + 推荐器，接通首页 |
| 工程与合规空白 | 无 README、无前端测试/typecheck/CI、无第三方声明；DSL 无校验、无许可证/来源字段；`types.ts` 与 `scene.json` 契约不一致 | DSL v2 + 校验器 + 可插拔包注册 + 快照哈希 + 测试/CI/README/NOTICES/合规报告 |

## 1. 目标架构（新增层次，不推翻 V2）

```
pc/src/
├── kernel/        ← 新增：平台无关科学计算内核（纯 TS，零依赖）

│   ├── ode.ts         Euler / SymplecticEuler / Verlet / RK4 / RK45自适应
│   │                 + 事件(零交叉) + 轨迹采样 + 能量漂移诊断

│   ├── units.ts       SI 7 维量纲向量、单位换算、量纲一致性校验
│   ├── fit.ts         WLS 线性/多项式、LM 非线性、R²/残差/参数置信区间/AIC

│   ├── rng.ts         mulberry32 / xorshift128+ / Box-Muller（可复现种子）

│   ├── hash.ts        纯 TS SHA-256（无 WebCrypto 依赖，兼容鸿蒙 WebView）

│   └── export.ts      HTML（内嵌 SVG）/ Markdown / CSV / JSON 快照
├── assistant/     ← 新增：离线检索增强助教
│   ├── retrieval.ts   BM25（中文二元字 gram + 英文 token）+ 索引构建

│   └── LearningCenter.vue 学习中心：掌握度、错题本、今日复习、推荐路径、档案切换

└── ExperimentStage.vue ← 修改：分析 Tab、快照导出、错题入库（最小侵入）
```

## 5. 风险与规避

| 风险 | 规避 |
|---|---|
| 鸿蒙 WebView 不支持 IndexedDB / WebCrypto | `db.ts` 自动降级 localStorage；`hash.ts` 纯 TS SHA-256，不依赖 `crypto.subtle` |
| 鸿蒙 bundle 必须全内联，禁止运行时 fetch JSON | 保留 `import.meta.glob` 编译期内联；运行时包只从内存/导入字符串注册 |
| 巨型组件 `ExperimentStage.vue`(1382 行) 改动易回归 | 最小侵入：只加 Tab 与事件调用，不改既有状态机；新功能集中在独立组件 |
| GPL 项目代码「参考过度」 | 明确红线：不打开其源码文件，仅阅读 README/文档/公开算法；合规报告留档 |
| 现有 WIP 未提交改动（鸿蒙闪屏 r8 相关） | 作为升级基线保留，随 V3 一起提交；鸿蒙 bundle 由构建重建覆盖 |

### 6.1 桥接设计要点

- **同步 API 不变**：`getProgress / markQuiz / markDone / entryScore / overallProgress / weakExperiments` 签名与语义保持 V2 行为，`getProgress()` 返回深拷贝。
- **双写降级**：同步路径写 localStorage（兼容鸿蒙 WebView 无 IndexedDB），异步串行写入新持久层，失败静默降级。
- **迁移只发生一次**：全系统首次启动（无任何 `progress.v2.*` 记录）时把 V2 localStorage 迁进 DB；已有其他档案而本档案为新档案时从空进度开始，**绝不继承别人的本地数据**（localStorage 是全局单键，否则会跨档案串数据）。

### 6.2 合规边界再确认

- 零新增运行时依赖；`esbuild` 只是把原本隐式使用的既有传递依赖显式声明为 `devDependencies`（MIT），`npm install --package-lock-only` 校验锁文件零差异，未引入任何新包。
- 新增脚本、测试与技能包文档均为本项目独立编写，未复制任何第三方代码、资源或文案。
- 巡检实测：**94 个依赖，允许 94 / 禁止 0 / 待复核 0 / 隐式导入 0**；GPL / AGPL / LGPL / SSPL / EUPL / CeCILL / MPL / EPL / CC-BY-NC 等由 CI 直接阻断，`NOASSERTION` 与未知标识一律待复核。
- **名称区分仍为未决产品决策**：内部代号 `SciLab` 与 Scilab 近似的改名涉及品牌与权利人决定，本轮不擅自变更，仅保留 README 无关联声明与风险提示。
