## 二、P0 梯队详细设计

### T1 时间控制中心

引擎 `core.ts` 渲染循环引入 `timeScale`，物理/解析积分步长统一乘以该系数；HUD 工具栏新增时间控制条。

```
[◀◀] [▶/⏸] [▶▶|单步] ──── 时间流速 ────●──── 1.0×
[● 录制]  [⏵ 回放]
```

- **慢动作**：0.1× / 0.25× / 0.5× / 1× / 2× / 5× / 10× 七档 + 滑杆连续调节
- **单步**：暂停态下每按一次推进 1/120s 并渲染一帧（碰撞、全反射瞬间教学利器）
- **录制回放**：录制 = 每帧把 `records + 关键物理状态` 序列化入环形缓冲（上限 60s@30fps）；回放 = 只读模式按帧重放，进度条可拖动

| 文件 | 改动 |
|------|------|
| `engine/core.ts` | `timeScale` 属性 + `stepOnce()` + `onFrame` 录制钩子 |
| `experiments/types.ts` | `ExperimentLogic.update(dt)` 语义不变（dt 已缩放） |
| `components/ExperimentStage.vue` | 时间控制条 UI + 录制/回放状态机 |

### T2 虚拟仪器手动测量（本方案最大差异化）

现状：数据全部自动记录，学生只是"看"。升级后每个实验可选 `instrument` 模式——**数据必须亲手测**：

| 虚拟仪器 | 交互 | 适用实验 |
|----------|------|----------|
| 🔴 秒表 | 独立启/停/归零按钮，精度 0.01s（人手反应延迟 ±0.2s 模拟） | 单摆周期、自由落体、碰撞 |
| 📏 刻度尺/数显标尺 | 3D 场景内可拖拽的测量线，学生手动对齐读数 | 斜面位移、平抛射程、弹簧伸长 |
| 🧪 量筒/温度计 | 侧边 HUD 放大刻度窗，视线平视读数（俯视/仰视读数偏差会被记录） | 化学酸碱、气体定律、浮力 |
| ⚡ 电表 | 指针式电压/电流表盘，量程切换（量程选错会"打表"扣分） | 欧姆定律、电路基础 |

工作流：`仪器读数 → 手动填入数据表 → DataPanel 拟合`，与真实实验室完全一致。

| 文件 | 改动 |
|------|------|
| `experiments/types.ts` | SceneDef 增加 `instruments: InstrumentDef[]`（类型/量程/精度） |
| `components/InstrumentPanel.vue` | **新建**：仪器 HUD（秒表表盘、刻度放大窗、电表指针盘） |
| `components/ExperimentStage.vue` | `manualMode` 开关：自动记录 ⇄ 手动记录切换 |
| `experiments/*/scene.json` | 8 个核心实验补 `instruments` 字段 |

### T3 对照实验 A/B 分屏

实验台支持双实例并排：左 A 右 B 各自独立 3D 视口 + 参数面板，共享时间控制（同步步进，保证可比）。

- 入口：实验列表卡片增加"对照"按钮 → 侧栏出现 A/B 两个实验槽
- 数据：A/B 两套 records 同屏显示在一张图（不同颜色标记），拟合线各自叠加
- 典型场景：摩擦 μ=0 vs μ=0.3 的斜面；大小摆长单摆；串联 vs 并联电路

| 文件 | 改动 |
|------|------|
| `components/ExperimentStage.vue` | 拆出单实验视口子组件，容器支持 1/2 实例布局 |
| `App.vue` | 对照模式路由 + A/B 槽位状态 |
| `components/DataPanel.vue` | 多数据集同图渲染（dataset 颜色区分） |

### T4 考核模式

SceneDef 新增 `exam` 段，考试入口在实验台顶部：

```jsonc
// scene.json 示例
"exam": {
  "timeLimitSec": 600,              // 限时
  "goals": [
    { "metric": "g", "expect": 9.8, "tolerance": 0.3, "weight": 60 },   // 数据精度 60 分
    { "metric": "records>=8", "weight": 20 }                            // 数据量 20 分
  ],
  "checklist": ["调整摆角<10°", "测满 30 次振动", "使用秒表手动计时"]  // 步骤分 20 分
}
```

评分 = **数据精度分**（测量值与真值之差在容差内按线性给分）+ **步骤完成分**（操作事件流匹配 checklist 关键词）+ **数据量分**。交卷后成绩写入 history（含考核标记），教师可凭历史记录验收。

| 文件 | 改动 |
|------|------|
| `experiments/types.ts` | `ExamDef` 接口 + 逻辑接口增加 `evaluate()` 钩子 |
| `components/ExamPanel.vue` | **新建**：倒计时、交卷、评分报告弹窗 |
| `store/history.ts` | 历史条目增加 `mode: 'practice' | 'exam'` |
| `experiments/*/scene.json` | 6 个核心实验补 `exam` 段 |

## 三、P1/P2 梯队要点

### T5 蒙特卡洛误差引擎
- Box-Muller 高斯噪声发生器，σ 由仪器等级决定（秒表 σ=0.2s 人的反应、卡尺 σ=0.5mm、量筒 σ=0.5mL）
- `sim` 值与 `measured` 值分离：3D 世界跑真值，数据表记含噪值
- DataPanel 数据点画**误差棒**，拟合输出 `a ± σa`（不确定度传播公式）

### T6 报告 2.0
- 在现有 HTML 报告基础上增加：误差分析段落（自动生成：最大误差源 + 改进建议模板）、拟合方程与 R²、**曲线图导出为内联 SVG 位图**嵌入报告（脱离应用可看）
- 增加"作业模式"：隐藏结论，留空让学生手填后打印

### T7 题库学习闭环
- `experiments/<id>/quiz.json`：预习检测 3 题（单选）+ 课后检验 3 题（单选/填空），答案与解析内置
- 流程：预习未达标弹提示但**不强制拦截**（自主性）→ 实验完成 → 课后检验 → 全部通过该实验标记 ✅
- App 学习进度升级为三层：预习/实验/检验各自占比，薄弱实验（检验正确率<60%）在首页生成"推荐重做"卡片

### T8 AI 诊断式助教 2.0
- 操作事件流埋点：`{t, type: 'param'|'start'|'record'|'instrument', detail}` 全程记录
- 规则引擎匹配 12 类典型错误模式，例：
  - 单摆：`摆角参数>15° 且 周期偏差>2%` → "摆角过大会引入系统误差，请将摆角调至 5°–10° 重测"
  - 欧姆定律：`电压表量程<读数` → "量程选择过小导致打表，回忆电表量程选择规则"
  - 斜面：`未等物块匀速就记录` → "数据记录过早，摩擦系数测量需要匀速段"
- 命中规则后以"⚠ 诊断"卡片形式出现在 AI 面板，而非被动等待提问

### T9 参数扫描与寻优
- "参数扫描"按钮：选定 1 个参数 + 区间 + 步数（如发射角 15°→75° 每 5°），后台无渲染批量仿真（headless 跑物理，跳过 3D），秒级出 13 组数据
- 自动寻优：黄金分割法在区间内逼近极值（最大射程角、最大功率电阻匹配）
- 结果直接进 DataPanel 绘制"参数-目标"曲线 + 标注极值点

## 五、风险与对策

| 风险 | 对策 |
|------|------|
| 双场景内存翻倍（three 双 WebGL 上下文） | A/B 各自独立 canvas，引擎实例化已隔离；2in1/低配设备默认提示 |
| 手动测量拖慢课堂节奏 | `manualMode` 可一键切回自动记录，教师自主选择 |
| 考核评分争议（容差设计） | exam 段完全在 scene.json 中声明式定义，教师可改包自定义 |
| 回放缓冲内存 | 环形缓冲 60s 上限，超出丢最旧帧，约 2MB 内存量级 |
